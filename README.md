# ESP32-S3 Data Logger

Data logger based on an ESP32 chip used for environmental data logging.

## How to Use

Arduino IDE 2.3.6

1. lvgl 8.3.11 installed
2. all other library according #include
3. compilation takes several minutes
4. Hard resseting via RTS pin ... is normal innformation after programming
5. check serial monitor after programming in case of errors


### App version

App_V1 - basic app, wi-fi connection, current time, openweather connection
